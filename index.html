01 / 강점

출시까지 책임진 경험

iOS 앱의 Android 포팅을 1인 담당해 크래시 디버깅부터 멀티 해상도 대응까지 처리하고 출시를 마쳤습니다.

측정으로 문제를 잡는 방식

썸네일 텍스처가 해제되지 않아 생기던 메모리 누적 크래시를 Unity Profiler로 특정하고, 실기기 계측으로 해결을 검증했습니다.

비개발 직군과의 협업

아티스트가 Unity 안에서 직접 이모티콘을 조합 · 편집하는 에디터 툴을 만들고, 피드백을 받아 UI를 개선했습니다.

02 / 실무 프로젝트

Mingle

주식회사 카이 · 2024.09 – 2025.09 · Unity 클라이언트 개발 (1년) · 메타버스 방송 플랫폼 · 팀 20명 · 인도네시아 App Store · Google Play 출시

썸네일 메모리 누적 크래시 해결

소집 패널을 반복해서 열면 썸네일 텍스처가 해제되지 않아 메모리가 쌓이고 앱이 크래시했습니다. Unity Profiler로 누적 지점을 특정하고, 패널 종료 시 캐싱된 텍스처를 명시적으로 Destroy했습니다.

iOS → Android 1인 포팅

Android Logcat으로 크래시를 분석하고, AndroidPostbuild 코드를 분석해 빌드 이슈를 해결했습니다. Manifest로 메모리 용량을 조정하고, 권한 설정 변환과 멀티 해상도 UI까지 맡아 Android 빌드 출시를 마쳤습니다.

멀티플레이 댄스 동기화

Photon PUN RPC 기반으로 플레이어 간 애니메이터를 동기화하고, 근거리 플레이어를 감지하는 거리 계산 로직을 구현해 실시간 상호작용 기능을 제공했습니다.

로그인 UI 아키텍처

UIView / PageView / PopupView 계층을 설계하고 UniTask로 페이지를 비동기 전환했습니다. ExecuteWithLoading으로 버튼별 로딩 상태를 관리해 중복 요청을 막고, 예외 상황에서도 UI 상태를 일관되게 유지했습니다.
